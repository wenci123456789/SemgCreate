SEMG迁移学习研究项目
这是一个基于表面肌电信号（sEMG）的手势识别和预测项目，主要利用迁移学习技术在不同用户之间进行模型适配。

项目概述
本项目专注于解决sEMG信号在跨用户场景下的手势预测问题。由于不同用户的生理差异，直接应用在一个用户上训练好的模型往往无法在其他用户上取得良好效果。为此，我们采用了多种迁移学习方法来提升模型在新用户上的表现。

技术架构
核心模型
EMGMamba系列模型：
基于Mamba架构的sEMG信号处理模型
包含注意力机制和Adapter模块
支持快速适应新用户（只需微调少量参数）

传统基线模型：
LSTM
RoFormer
Transformer
TCN
BERT

迁移学习方法
微调（Fine-tuning）：
在目标用户数据上微调预训练模型的部分参数
对抗迁移学习（ATL）：
使用对抗训练减少源域和目标域之间的分布差异
CDAN-R++：
结合条件域对抗网络和正则化技术的高级迁移方法

数据集
项目主要使用NinaPro DB2数据集：
源域：S1-S30用户的数据用于预训练
目标域：S31-S40用户的数据用于迁移学习测试
每个用户包含6次重复动作，其中5次用于训练，1次用于测试
